Ce guide détaille les captures d'écran à réaliser pour compléter la présentation PowerPoint.

## 🛠️ Outils Recommandés

### Pour capturer les screenshots :

**Windows** :
- `Win + Shift + S` : Outil de capture intégré
- **Snipping Tool** : Plus d'options
- **ShareX** (gratuit) : Capture + annotations

**macOS** :
- `Cmd + Shift + 4` : Sélection zone
- `Cmd + Shift + 3` : Plein écran
- **CleanShot X** (payant) : Professionnel

**Linux** :
- `gnome-screenshot` : Intégré
- **Flameshot** (gratuit) : Très complet

**Extensions navigateur** :
- **Awesome Screenshot** : Capture + annotation
- **Nimbus Screenshot** : Capture scrolling complet
- **Fireshot** : PDF multi-pages

## ✂️ Post-traitement

### Édition recommandée :

1. **Recadrer** : Supprimer les bords inutiles
2. **Annoter** : Ajouter flèches/cercles pour attirer l'attention
3. **Flouter** : Masquer données sensibles (noms, emails réels)
4. **Redimensionner** : 1920x1080px ou ratio 16:9
5. **Optimiser** : Compresser sans perte de qualité (TinyPNG.com)

### Outils d'édition :

- **Canva** (gratuit) : Annotations + texte
- **GIMP** (gratuit) : Retouche avancée
- **Photoshop** (payant) : Pro
- **Paint.NET** (Windows, gratuit) : Simple et efficace

---

## 📐 Spécifications Techniques

| Paramètre | Valeur recommandée |
|-----------|-------------------|
| **Format** | PNG (qualité) ou JPG (taille) |
| **Résolution** | 1920x1080px minimum |
| **Ratio** | 16:9 (pour slides) |
| **Poids** | < 2 MB par image |
| **DPI** | 72-96 DPI (écran) |

---

## 🎨 Cohérence Visuelle

### À respecter :

✅ **Thème cohérent** : Toutes captures avec même thème (clair/sombre)
✅ **Même navigateur** : Chrome ou Firefox pour toutes
✅ **Zoom standard** : 100% (pas de zoom navigateur)
✅ **Barre d'outils** : Masquer si possible (F11 plein écran)
✅ **Données tests** : Utiliser noms fictifs cohérents

### À éviter :

❌ Données réelles/sensibles
❌ Captures floues ou pixelisées
❌ Mélange de thèmes clair/sombre
❌ Trop de barre d'outils visible
❌ Fenêtres redimensionnées bizarrement

## 🚀 Utilisation dans le PowerPoint

Une fois les captures réalisées :

1. **Placer les images** dans `/workspaces/SIGAC/images/`
2. **Vérifier les noms** correspondent exactement :
   - `logo-taajii.png`
   - `dossiers-liste.png`
   - `dossier-detail-documents.png`
   - `utilisateurs-gestion.png`
   - `chat-interface.png`
   - `calendrier-evenements.png`
   - `dashboard-statistiques.png`
   - `interface-responsive.png`
   - `login-page.png`

3. **Convertir en PowerPoint** :
```bash
pandoc PRESENTATION_TAAJII_PPT.md -o PRESENTATION_TAAJII.pptx
```

4. **Vérifier** dans PowerPoint que toutes les images apparaissent

5. **Ajuster si besoin** :
   - Taille des images
   - Position sur les slides
   - Ordre avec le texte
