## Slide 16 : Workflow Exemple (Juridique)

### Cycle de vie d'un dossier

1. 📩 **Dépôt de requête** → Statut "Nouveau"
2. 👤 **Attribution rapporteur** → Statut "En instruction"
3. 📅 **Audience planifiée** → Ajout au calendrier
4. ⚖️ **Délibéré** → Statut "En délibéré"
5. ✅ **Jugement rendu** → Statut "Jugé" + Document PDF
6. 📦 **Archive** → Statut "Archivé"
